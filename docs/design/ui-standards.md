# คู่มือมาตรฐาน UI/UX Design System (Pik a Class)

เอกสารนี้สรุปข้อกำหนดด้าน UI/UX และ Design System สำหรับแพลตฟอร์ม **Pik a Class** เพื่อให้นักพัฒนาและ AI ยึดถือเป็นมาตรฐานเดียวกัน

---

## 1. คำศัพท์ที่เป็นมิตรกับผู้เรียน (Kid-Friendly Lexicon)
- **หลีกเลี่ยงศัพท์เทคนิคในหน้าจอผู้เรียน:**
  - เปลี่ยน "แดชบอร์ด (Dashboard)" ➔ "หน้าหลัก" (Home)
  - เปลี่ยน "Repository / Content Bank" ➔ "คลังบทเรียน / คลังคำศัพท์"
  - เปลี่ยน "Tier" ➔ "ระดับสมาชิก" หรือ "สิทธิ์การเรียน"

---

## 2. โครงสร้างหน้าหลัก 4 โซนกิจกรรม (Home 4-Zone Hub)
หน้าแรกของระบบแบ่งกิจกรรมออกเป็น 4 การ์ดอิสระ เรียงตามลำดับ:
1. 🚀 **ตะลุยด่านภาษาอังกฤษ:** โหมดหลัก ตะลุยด่านสะสมดาว A1–B2 (`learn/index.html`) — ธีมเขียวมิ้นต์ (`#37c871`)
2. ☕ **Animal Cafe:** มินิเกมเสิร์ฟคำศัพท์ สะสมคอมโบ และโหมด Endless (`vocab/cafe.html`) — ธีมส้มคาเฟ่ (`#ea580c`)
3. 📖 **คู่มือสรุปไวยากรณ์:** สรุป 40 หัวข้อหลัก โครงสร้างสูตร ตัวอย่างประโยค (`handbook.html`) — ธีมน้ำเงินความรู้ (`#2563eb`)
4. 🗂️ **คลังคำศัพท์:** ท่องศัพท์ การ์ด 3D ฟังเสียงอ่าน (`vocab/index.html`) — ธีมม่วงสดใส (`#7c3aed`)

---

## 3. ระบบปุ่มย้อนกลับความชัดเจนสูง (High-Visibility Back Nav)
- ทุกหน้ารองต้องมีปุ่มย้อนกลับที่สังเกตเห็นได้ใน 1 วินาที
- ใช้คลาส `.btn-nav-back` สไตล์ Chunky 3D นูนหนา
- พื้นที่สัมผัสขั้นต่ำ $44 \times 44\text{px}$ ตามมาตรฐาน WCAG 2.2 AA
- มีลูกศร `←` เด่นชัด และข้อความระบุชัดเจน เช่น `← กลับหน้าหลัก`

---

## 4. มาตรฐานปุ่ม 3D Chunky และ Tactile Feedback
- ปุ่มหลักใช้ขอบล่าง 3-4px เมื่อกดแล้วจมลง 2px (`transform: translateY(2px)`)
- ใช้ `@media (hover: hover) and (pointer: fine)` ป้องกัน Hover ค้างบนมือถือ
- รองรับเสียงคลิกและเสียงตอบคำถามเพื่อเสริมแรงจูงใจ
